# Quiz后台管理系统

基于 Vue 2 + Element UI 的 Quiz 后台管理界面作业。

## 功能页面

### 用户管理（/user）
- 顶部标题栏：Quiz后台管理
- 左侧侧边栏：系统信息管理（用户管理、题目管理菜单）
- 搜索栏：用户名输入框 + 查询用户按钮 + 添加用户按钮
- 用户列表：日期、用户名、密码、操作（编辑/删除）
- 分页组件
- 添加用户弹窗

### 题目管理（/question）
- 布局与用户管理一致
- 搜索栏：题目关键词输入框 + 查询题目按钮 + 添加题目按钮
- 题目列表：序号、问题、选项、答案、操作（编辑/删除）
- 分页组件
- 添加题目弹窗

## 本地运行

```bash
# 安装依赖
npm install

# 本地开发运行（端口7000）
npm run serve

# 浏览器访问
http://localhost:7000
```

## 编译打包

```bash
npm run build
```

编译产物会生成在 `dist/` 目录下。

## 提交要求

### 1. GitHub 源代码仓库
- 将整个项目源代码推送到第一个 GitHub 仓库
- `.gitignore` 已配置忽略 `node_modules` 和 `dist`

### 2. 编译产物仓库
- 新建第二个 GitHub 仓库
- 将 `npm run build` 生成的 `dist` 目录下的所有文件推送到第二个仓库

### 3. Vercel 部署
- 在 Vercel 中导入第二个仓库（dist 仓库）
- 部署后获得公开可访问的页面链接

### 提交内容
1. Vue 源代码 GitHub 仓库地址
2. Vercel 部署后的可访问页面链接
